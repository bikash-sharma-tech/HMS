# 🏥 Hospital Management System 

This project is a fully functional Hospital Management System built during a freelance engagement. It is currently deployed in a live environment and supports the hospital staff in managing IPD, OPD, and Pathology operations.

> 📌 *Note: This repository only contains UI screenshots and feature documentation. Source code is proprietary and not publicly available.*

---

## 🚀 Tech Stack

- **Backend**: .NET
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap, Jquery, 
- **Database**: SQL Server
- **Architecture**: Role-Based Access, Modular Design, 3-Tier Architechture

---

## 🧩 Modules & Features

### 1️⃣ In-Patient Department (IPD)

Manages admitted patients including their room, treatment, billing, and discharge.

**Key Features**:
- 🛏️ **Bed & Room Management**: Allocate/track bed availability, room pricing
- 🏥 **Patient Admission**: Register admitted patients with detailed medical info
- 💰 **Advance Collection**: Accept and record advance payments
- 🩺 **Operation Module**: Record surgeries, OT schedule, surgeon notes
- 📤 **Discharge Summary**: Auto-generate final reports with medical and billing history
- 💳 **Billing**: Generate itemized bills and adjust with advances
- 🧾 **History Tracking**: Maintain complete records for returning patients

### 2️⃣ Out-Patient Department (OPD)

Streamlines the outpatient workflow from registration to receipt generation.

**Key Features**:
- 🎫 **OPD Ticketing**: Generate unique visit tickets with doctor assignment
- 🧍‍♂️ **Consultation Logs**: Record symptoms, diagnosis, and treatment advice
- 📜 **Visit History**: View patient consultation timeline and revisit notes

### 3️⃣ Pathology Module

Handles test requisitions, result entries, and lab report generation.

**Key Features**:
- 🧪 **Test Request Management**: Doctors can request diagnostic tests
- 🔬 **Sample & Status Tracking**: Monitor lab sample processing
- 📥 **Manual/Auto Entry**: Enter or import results based on test type
- 📄 **PDF Report Generation**: Generate patient-ready lab test reports
- 🔐 **Access Control**: Only authorized lab staff can modify reports

## 🔐 Role-Based Access

| Role           | Access Permissions                                   |
|----------------|------------------------------------------------------|
| **Admin**      | Full system access and user management               |
| **Doctor**     | Patient treatment, test requests, discharge notes    |
| **Receptionist** | Admission, OPD, billing                             |
| **Lab Technician** | Test result entry and report generation         |
| **Billing Clerk** | Final invoice, receipt printing           |
